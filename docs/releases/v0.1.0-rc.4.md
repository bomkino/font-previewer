# Font Previewer v0.1.0-rc.4 — release candidate notes

This prerelease adds a calmer reading lane to Simple while keeping the original four-font comparison workflow intact.

## Body Copy

- Choose **Body Copy** beside **Boards** in Simple.
- See one included font per page, with full text rather than a clipped card excerpt.
- Start from three original two-paragraph samples or write custom copy up to 1,200 characters.
- Compare every family at one shared fitted reading size, borrowing Studio's equal-comparison discipline without exposing Studio's complexity.
- Export verified 5,152 × 2,160 PNGs to `Body Copy/Body_XX.png` inside the normal transactional Handoff.

## Boards remain whole

The original Simple lane is still present: four fonts per board, four colour quadrants, stress text, five casing modes including AP Title, variable axes, order and include controls, full-size preview, Same size / Fit each / Lock line breaks, optional 12-font index pages, and exact-size PNG export.

## One session, two depths

Body Copy uses the same Candidates, selected styles, axes, casing, order, include decisions, comparison policy, and live copy as Boards and Studio. Switching depth does not create a second project or a synchronized shadow model.

## Interface and integrity

- Simple now leads with one large Boards / Body Copy format choice and uses a roomier editorial layout, larger controls, clearer grouping, and warm reading surfaces inside the dark-first application.
- Both Hosts validate the selected Simple format, page counts, candidate counts, PNG structure, decoded dimensions, and checksums before commit.
- The macOS Host canonicalizes export roots and outputs before writing relative manifest paths, including `/var` and `/private/var` aliases.
- A failed or malformed export removes staging and leaves any prior Handoff untouched.

## Installation boundary

- macOS 13+ Apple Silicon: hardened runtime and ad-hoc signature; no Developer ID or notarisation. Verify `SHA256SUMS`, attempt one launch, then use macOS **Privacy & Security → Open Anyway** if needed. A global Gatekeeper disable is neither required nor recommended.
- Ubuntu/Debian x64: hosted X11 journey and native Wayland/Ozone smoke; independent-machine acceptance remains pending.
- Browser build: development fallback only.

## Known limitations

This candidate does not claim attended VoiceOver or Orca acceptance, human approval of every typeface/script/reading size, independent clean-machine reconstruction, universal platform behavior, broad hostile-font containment, a real induced WKWebView content-process termination, or Apple notarisation. Those remain stable-release or stronger-support gates.
