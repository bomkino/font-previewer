# Font Previewer v0.1.0-rc.3 — release candidate notes

This prerelease restores the fast original Font Previewer journey without throwing away the deeper Studio.

## Simple first

- Add local font files or folders, or browse the Host-local installed-font Catalog.
- Choose a whole family or inspect its styles and add only the source/style you want.
- See four fonts per board immediately.
- Change the copy, run the stress set, switch casing including AP Title, tune variable axes, reorder fonts, include or skip them, and open a full-size preview.
- Use Same size, Fit each, or Lock line breaks.
- Export verified 5,152 × 2,160 four-up PNG boards plus optional 12-font index pages.

## One Study, two views

Simple and Studio use the same session. Imported fonts and styles, copy, casing, axes, order, decisions, and comparison sizing carry across the mode switch. Studio adds structured Review, saved and blind Compare sets, System Roles, and a complete transactional Handoff.

## Interface rebuild

- Dark by default.
- Oversized editorial hierarchy and clearer journey.
- Larger icons and controls, consistent square geometry, and more breathing room.
- 80–140% interface scaling in 10% steps with keyboard shortcuts.
- Rebuilt Studio stages with contextual chrome and a full-width Handoff surface.
- No title or candidate ellipsis in the retained native evidence states.

## Export and integrity

Both Hosts validate every renderer-produced board PNG before commit, including its signature, chunks, CRCs, dimensions, decoded size, and scanline filters. Export still stages, hashes, verifies, and atomically commits; a failure removes staging and preserves any earlier export byte-for-byte.

## Installation boundary

- macOS 13+ Apple Silicon: hardened runtime and ad-hoc signature; no Developer ID or notarisation. Verify `SHA256SUMS`, attempt one launch, then use macOS **Privacy & Security → Open Anyway** if needed.
- Ubuntu/Debian x64: hosted X11 journey and native Wayland/Ozone smoke; independent-machine acceptance remains pending.
- Browser build: development fallback only.

## Known limitations

This candidate does not claim attended screen-reader acceptance, competent complex-script approval, independent clean-machine reconstruction, universal platform behavior, broad hostile-font containment, a real induced WKWebView content-process termination, or Apple notarisation. Those remain stable-release gates.
