# Font Previewer v0.1.0-rc.5

This release candidate adopts the pitch.dog type system as the bundled interface typography, moves core controls to Phosphor Icons, and tightens spacing, keyboard scope, blind-comparison privacy, and package integrity.

## pitch.dog typography, locally bundled

- The interface now consumes pitch.dog Type System 13.0.0 from exact commit `786b4a2b671182319320f922b8de8f927ea3a002`.
- Head, Body, Body Alt, and Eyebrow have defined interface jobs instead of depending on whichever fallback happens to exist on one machine.
- Seven fixed WOFF2 files ship with the renderer, so the interface needs no font installation, runtime network request, or browser token.
- The seven binaries are CC0-1.0. The surrounding type-system CSS and code remain pitch.dog-owned material and are not relicensed under Font Previewer's MIT licence.
- Candidate specimens remain isolated under their generated `FontPreviewer_<hash>` families. The brand fonts do not replace, disguise, package, or grant redistribution rights over a user's Sources.

## One icon language

Phosphor Icons for React 2.1.10 replaces improvised Unicode marks and bespoke one-off SVG paths across core actions, page modes, source health, review decisions, reordering, status, and Handoff preflight. Accessible control names remain text or explicit ARIA labels; decorative icon instances stay hidden from the accessibility tree.

## Space and hierarchy

- A 4 px spacing scale now governs recurring padding and gaps.
- Primary controls use a 56 px height with shared inline padding and radii.
- Head carries major moments; Body carries productive interface copy; Body Alt carries selected lead copy; Eyebrow carries metadata and data.
- Stable scrollbars reduce layout jumps, while high interface scales collapse secondary titlebar labels and narrow Studio columns instead of squeezing core work.
- Press feedback stays subtle, quick, and disabled under reduced-motion preferences.

## Package integrity

One auditor scans file extensions and binary magic, then requires all seven approved interface fonts at their exact byte sizes and SHA-256 digests. It rejects omissions, duplicates, alterations, disguised fonts, extra fonts, and valid fonts outside the sole approved assets directory.

The build, unpacked Linux package, macOS application, Linux portable archive, and Debian package use the same identity contract. Both displayed Hosts wait for the required interface faces and two animation frames before taking visual evidence.

## Interaction fixes

- Review-state and tray keyboard shortcuts now work only in Studio Review.
- Arrow navigation follows the currently visible filter/search result instead of selecting a hidden Candidate.
- Inspector now follows Compare's live blind/reveal state, including before a comparison set is saved, so the side panel cannot reveal a hidden identity.
- Font intake copy now describes the supported chooser rather than implying unsupported drag-and-drop.

## Installation boundary

- macOS 13+ Apple Silicon: hardened runtime and ad-hoc signature; no Developer ID or notarisation. Verify checksums before using macOS **Privacy & Security → Open Anyway** when required.
- Ubuntu/Debian x64: hosted X11 and native Wayland/Ozone evidence remain required for the exact candidate SHA; independent-machine acceptance remains pending.
- Browser build: development fallback only.

## Known limitations

This candidate does not claim attended VoiceOver or Orca acceptance, human approval of every layout/typeface/script relationship, independent clean-machine reconstruction, universal platform behavior, broad hostile-font containment, a real induced WKWebView content-process termination, or Apple notarisation. Those remain human, stable-release, or stronger-support gates.
