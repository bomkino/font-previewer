# Font Previewer v0.1.0-rc.2 — release candidate notes

Published as a GitHub prerelease on 2026-08-28 after an exact-SHA dry run and exact-source verification.

## What changed since v0.1.0-rc.1

- Canonicalised the merged RC, hardening, and pre-Mac implementation on `main`.
- Added bounded Linux font metadata and variable-axis inspection with forced termination and output ceilings.
- Expanded malformed font-header, protocol, Study, recovery, Handoff-failure, and forced Electron renderer-recovery evidence.
- Added forced-colours support and retained reduced-motion behavior.
- Removed production source maps and added package inventory, private-path, credential-marker, source-map, licence, notice, SBOM, and font-binary audits.
- Made Linux `.deb` and portable package output reproducible from `SOURCE_DATE_EPOCH`.
- Added hosted native Wayland/Ozone launch-and-render evidence alongside the complete X11 journey.
- Added exact-head checkout, exact-SHA artifact names, `SOURCE_SHA` manifests, and a version-consistency gate.
- Replaced historical one-release publishing code with a manual, exact-run, non-overwriting, dry-run-first release workflow.
- Reconciled current documentation, archived branch-era evidence, and removed obsolete branch instructions.
- Made the AppKit/WKWebView Host the default Mac build/install path; retained the older SwiftUI/CoreText app as an explicit reference build.
- Rejected descriptor-free OTF/TTF/WOFF/WOFF2 inputs before preview binding, while retaining valid WOFF/WOFF2 CoreText support.
- Fixed focused-edit Save, native text undo, keyboard skip-link focus, and recovery flushing before ordinary quit or last-window close.
- Made bracketed workspace paths and emitted-test counts part of the test launcher contract; added a 100-card Review regression surface.
- Added one responsive icon system across macOS, Linux, Studio chrome, favicons, and the web manifest; the coral loupe reveals a letter's changing typographic character.
- Made the Studio dark by default, independent of the operating-system appearance setting.

The exact architecture label is derived from the verified package binary. The workflow refuses unknown architecture, stale CI artifacts, mismatched source SHAs, failed checksums, existing tags/releases, or packages containing font binaries.

## Installation boundary

- macOS 13+ Apple Silicon package: hardened runtime, ad-hoc signature, not Developer-ID signed or notarised.
- Ubuntu/Debian x64 packages: full hosted X11 journey and native Wayland/Ozone smoke; independent Linux machines remain pending.
- Browser build: development fallback only.

## Known limitations

This candidate does not claim:

- attended VoiceOver or Orca usability;
- human typography, native-interface, or competent complex-script approval;
- independent clean-machine Study/Handoff reconstruction;
- broad reference-hardware performance;
- hostile cross-format font containment beyond current automated fixtures;
- induced WKWebView content-process termination in a real packaged session;
- Developer ID signing, notarisation, stapling, or Gatekeeper acceptance;
- universal macOS or Linux support.

These limitations block stable `v1.0.0`, not canonical maintenance of prerelease code on `main`.
