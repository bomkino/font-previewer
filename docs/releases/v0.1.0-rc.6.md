# Font Previewer v0.1.0-rc.6

This release candidate completes a focused interface-fit pass: controls align more predictably inside their containers, select and disclosure carets use Phosphor consistently, expansion no longer snaps, and exact displayed evidence now guards the geometry.

## Carets and container fit

- Every product select uses an 18 px bold Phosphor caret with a 16 px right inset.
- Select text reserves 48 px for the caret, preventing label/icon collisions while preserving a deliberate internal gap.
- Inspector disclosure rows use the same icon family and a 12 px label gap.
- Icon-only actions use shared grid centering; mixed icon/text buttons use shared inline alignment and line height.
- Reorder and tray actions do not shrink when neighbouring copy grows.
- Compare's three footer actions now form one balanced icon group with unchanged accessible names.

## Expansion and dialog motion

- Inspector sections keep a stable mounted shell and animate a grid track, opacity, and a 4 px vertical offset over 120–180 ms.
- The disclosure caret rotates with the section; collapsed content becomes inert and leaves the focus order.
- Dialogs enter with a small 8 px rise and 1.5% scale correction over 160–180 ms.
- All motion is short, interruptible, property-specific, and removed when the operating system requests reduced motion.

## Displayed layout gates

Both packaged Host journeys now record and assert:

- minimum productive-control height;
- icon-only button center deltas;
- select-caret center deltas and right-edge clearance;
- Catalog, workspace, and Inspector top/bottom alignment;
- workspace/tray boundary continuity;
- panel-level horizontal overflow;
- disclosure expanded/collapsed semantics, inertness, intermediate motion frames, and caret return.

The semantic suite also verifies all custom select and disclosure shells and rejects regressions back to native `details`/`summary` controls.

## Installation boundary

- macOS 13+ Apple Silicon: hardened runtime and ad-hoc signature; no Developer ID or notarisation. Verify checksums before using macOS **Privacy & Security → Open Anyway** when required.
- Ubuntu/Debian x64: hosted X11 and native Wayland/Ozone evidence are required for the exact candidate SHA; independent-machine acceptance remains pending.
- Browser build: development fallback only.

## Known limitations

This candidate does not claim attended VoiceOver or Orca acceptance, human approval of every layout/typeface/script relationship, independent clean-machine reconstruction, universal platform behavior, broad hostile-font containment, a real induced WKWebView content-process termination, or Apple notarisation. Those remain human, stable-release, or stronger-support gates.
