# Contract Sketches

These files encode decisions precisely enough for R0 prototypes.

They are **not** stable production interfaces until D09 Contract Freeze A.

Rules:

- runtime validation is required at every process boundary;
- generated language bindings may be used after one canonical schema source is selected;
- do not hand-edit two authoritative copies;
- changes before D09 remain prototype changes;
- changes after D09 require compatibility/migration review.
