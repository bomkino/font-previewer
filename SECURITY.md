# Security

Font files, Study documents, dropped folders, renderer messages, and export destinations are untrusted input.

Do not disclose a suspected vulnerability in a public issue. Send a concise report to `hello@pitch.dog` with affected commit, reproduction steps, impact, and any proof-of-concept material that is safe to share.

The active threat model and release controls live in `docs/programme/handover/12_TEST_SECURITY_RELEASE.md`.
